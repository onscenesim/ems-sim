# Project instructions

This simulator depends heavily on what players see and hear. For every change to this project, use the Codex side preview before calling the work complete. Run the local app or a focused preview page, open it in the side browser, and check the affected state and interaction there. For visual or animation changes, inspect both the starting and ending states and exercise the transition. For sound changes, trigger the cue in the preview and check its timing and level when audio playback is available.

Keep the relevant preview open for the user at handoff. If preview access is blocked, report the specific blocker and say what could not be verified. Passing code tests alone does not count as preview verification.
